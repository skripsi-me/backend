## CODING STANDARDS & NAMING CONVENTIONS
1. **TypeScript:** Strict mode must be enabled (`"strict": true` in `tsconfig.json`).
2. **Linting:** Code must adhere to standard ESLint rules prior to execution.
3. **Formatting:** Code must be structured using Prettier configuration.
4. **Naming Conventions:**
   * Database Schema / Tables / Columns: `snake_case`
   * Classes / Types / Interfaces: `PascalCase`
   * Functions / Methods / Variables: `camelCase`
